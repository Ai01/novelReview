文档信息
文档名称：小说阅读 App 产品需求文档
版本：V1.0
设计稿来源：移动端 12 页面原型（登录、探索、书库、书籍详情、书单、个人中心、设置、底部弹窗）
目标：定义产品功能、页面逻辑、交互、数据结构，可直接用于 UI 还原、后端接口开发、OpenAPI 设计
1. 产品概述1.1 产品定位一款轻量化暖色系小说阅读社区 App，主打书籍浏览、书籍点评、书单收藏、个人中心管理，面向移动端用户，提供沉浸式阅读社区体验，整体视觉采用米白 + 浅棕极简柔和风格。1.2 核心目标
实现用户账号体系：登录、个人资料修改、退出登录
实现书籍基础能力：浏览、搜索、详情查看、点评、收藏
实现书单体系：书单浏览、书单详情、创建 / 管理书单
实现个人资产：我的点评、我的收藏书单、我的收藏书籍
实现系统设置：密码、头像、用户名、邮箱修改
1.3 用户角色
普通用户：浏览书籍、发表点评、收藏书籍 / 书单、创建书单、修改个人资料
2. 页面清单与功能详细需求2.1 页面总览（共 12 个页面 / 弹窗）
登录页 LOGIN PAGE
探索页 EXPLORE PAGE
书库页 LIBRARY PAGE
书籍详情页 BOOK DETAIL PAGE（2 个重复样式，统一逻辑）
设置页 SETTINGS PAGE（2 个重复样式，统一逻辑）
书单页 BOOKLISTS PAGE
书单详情页 BOOKLIST DETAIL PAGE
个人中心页 PROFILE PAGE
底部弹窗 BOTTOM SHEET MODAL（70% 高度，点评 / 书单操作）
2.2 各页面详细需求2.2.1 登录页 LOGIN PAGE页面布局
顶部：App 名称「小说」、英文 novel App
输入区：用户名输入框、密码输入框
操作区：登录按钮（浅棕色圆角）
底部：无其他控件
功能需求
用户输入用户名 + 密码，点击登录
校验账号密码，成功后跳转【探索页】，返回登录 Token
校验失败：提示错误信息
无注册入口，默认账号由后台创建
2.2.2 探索页 EXPLORE PAGE页面布局
顶部：页面标题「探索」、搜索框（可输入关键词搜索书籍）
内容区：书籍信息流列表，每一项包含：

书籍名称、作者、简介片段、评论数、点赞 / 浏览数据


底部：全局底部导航栏（首页 +、书库、书单、我的）
功能需求
默认展示推荐书籍列表，分页加载
支持顶部搜索框关键词搜索书籍
点击单条书籍，跳转【书籍详情页】
底部导航可切换页面
2.2.3 书库页 LIBRARY PAGE页面布局
顶部：页面标题「书库」、搜索框
内容区：分类书籍卡片，展示书籍封面、名称、状态（连载中 / 已完结）、收藏按钮
底部：全局底部导航栏
功能需求
按分类 / 状态展示书籍（连载中、已完结）
支持书籍收藏 / 取消收藏
点击书籍卡片，跳转【书籍详情页】
支持顶部关键词搜索
2.2.4 书籍详情页 BOOK DETAIL PAGE页面布局
顶部：书籍封面、名称、作者、状态、更新时间、收藏星星按钮
中部：点评区域（点评标题、所有用户点评列表）
底部：全局底部导航栏；可唤起底部弹窗发表点评
功能需求
展示书籍完整信息：封面、书名、作者、类型、更新时间、简介
展示书籍下所有用户点评：用户昵称、点评内容、点赞数、评论时间
支持收藏 / 取消收藏本书
支持添加本书到自定义书单
唤起底部弹窗，发布新点评
2.2.5 书单页 BOOKLISTS PAGE页面布局
顶部：页面标题「书单」、搜索框（搜索点评书籍、书单）
内容区：多格书单卡片，展示书单封面、名称、简介片段
底部：全局底部导航栏
功能需求
展示系统 / 用户创建的书单列表
支持关键词搜索书单
点击书单卡片，跳转【书单详情页】
2.2.6 书单详情页 BOOKLIST DETAIL PAGE页面布局
顶部：书单封面、标题
内容区：书单内书籍列表、书单下用户点评
底部：全局底部导航栏；可唤起底部弹窗操作
功能需求
展示书单内包含的所有书籍
展示书单下用户点评
支持新增书籍到书单、发布书单点评
2.2.7 个人中心页 PROFILE PAGE页面布局
顶部：用户头像、用户名
功能列表：

我的点评
我收藏的书单
我收藏的书籍
设置
退出登录


底部：全局底部导航栏
功能需求
展示当前登录用户基础信息
点击【我的点评】：查看自己发布的所有书籍 / 书单点评
点击【我收藏的书单】：查看收藏的全部书单
点击【我收藏的书籍】：查看收藏的全部书籍
点击【设置】：跳转设置页
点击【退出登录】：清除 Token，返回登录页
2.2.8 设置页 SETTINGS PAGE页面布局
顶部：返回按钮、页面标题「设置」
功能列表：

修改密码
修改头像
修改用户名
修改邮箱


功能需求
修改密码：输入旧密码、新密码，确认修改
修改头像：上传图片，更新用户头像
修改用户名：输入新昵称，更新
修改邮箱：输入新邮箱，绑定更新
所有修改操作需鉴权
2.2.9 底部弹窗 BOTTOM SHEET MODAL（70% 高度）弹窗布局
弹窗顶部标签：点评书籍 / 添加新书 / 添加书单
内容区：下拉选择、文本输入框（输入点评内容）
底部：提交按钮
功能需求
三种模式：发表书籍点评、添加新书、添加书单
输入内容后点击【提交】，完成对应操作
点击右上角 ×，关闭弹窗
3. 全局通用需求3.1 底部导航全局通用所有主页面固定底部导航：
首页（探索）
书库
书单
我的（个人中心）
点击可切换对应页面
3.2 视觉规范
主色调：米白色背景 + 浅棕色强调色（按钮、标题栏）
字体：常规无衬线字体，层级清晰
圆角：所有按钮、输入框、卡片均为圆角设计
弹窗：底部弹窗占屏幕 70% 高度，半透明遮罩
3.3 鉴权规则
无需登录：浏览书籍、书单、书籍详情、查看点评
必须登录：收藏、发表点评、修改个人资料、退出登录、创建书单
4. 核心业务数据模型4.1 用户 User
用户 ID、用户名、昵称、头像 URL、邮箱、密码（加密）、登录 Token
4.2 书籍 Book
书籍 ID、书名、作者、封面图、简介、状态（连载 / 完结）、更新时间、评分
4.3 点评 Comment
点评 ID、关联书籍 / 书单 ID、用户 ID、点评内容、发布时间、点赞数
4.4 书单 BookList
书单 ID、书单名称、封面、创建用户 ID、包含书籍 ID 列表、是否收藏
5. 非功能需求
性能：列表分页加载，单页 20 条内，接口响应≤300ms
兼容性：适配移动端 iOS/Android，弱网友好
安全：密码加密存储，Token 有效期 7 天，敏感信息脱敏
扩展性：预留阅读页面、消息通知、书籍推荐功能
